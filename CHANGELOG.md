# Changelog

## 0.1.0 — initial release candidate

- Shared Buzz ARENA with authorized human kickoff, separate review threads, Claude/Codex collaboration, and evidence-linked analysis.
- Unpublished commits, explicit Git bases, GitLab MRs (including self-hosted instances), and GitHub PRs (including fork PRs and configurable Enterprise hosts).
- Exact pinned revisions, shared surrounding source access, neutral Codex preparation, bounded discussion, and explicit omissions.
- Original sprites, contact-based combat, chiptune soundtrack, token fatigue, reversible scoring, unique specials, and character-specific finishers.
- Persistent replay, source/evidence drawers, Markdown/JSON exports, reduced motion, and an optional authenticated ngrok viewer.
- Configurable permanent viewer URL, bind address/port and environment overrides, with foreground server/container operation, readiness checks, persistent viewer links, key rotation, and nginx/Docker examples.
- Read-only reviewer capabilities, per-review usage attribution, and clearly labeled demo fixtures.

Live Buzz support is verified on macOS with Buzz 0.5.23. Repository code execution and automatic provider-session recovery after a crash are not included. See [verification](docs/verification.md) for tested scope.
